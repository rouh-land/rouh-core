Put Rouh on your projector

Looking for your projector...

  1. Write Raspberry Pi OS to the SD card

    On this computer, open Raspberry Pi Imager (free, from raspberrypi.com/software). Choose Raspberry Pi 3, then Raspberry Pi OS Lite (64-bit) under Raspberry Pi OS (other), then the SD card, and write it. Skip the settings it offers: the file below has them.

  2. Download this projector's setup file

    Written into the file on this computer only. Rouh never receives it.

    Rouh's address

  3. Put the file on the card

    The card shows up on this computer as a drive called bootfs. Drag the downloaded file user-data onto it, choose Replace, then eject the card.

  4. Plug it in

    Put the card in the Pi, connect the Pi to the projector with an HDMI cable, then plug in its power. The first start takes about 15 minutes while it sets itself up; after that it shows your Robot Chat about a minute after power on, every time.
